Sales & Revenue Analysis Dashboard

Project Description

This project is a Sales & Revenue Analysis Dashboard created to analyze sales, revenue, profit, products, and regions using data visualization.

Key Features

- Import sales data from Excel
- Calculate total sales, revenue, and profit
- Analyze top-performing products
- Display revenue trends
- Use charts for better data visualization
- Provide simple business insights

Technologies Used

- Python
- Excel
- Pandas
- Matplotlib

Files Included

- "app-1.py" – Python application
- "Sales & Revenue Analysis.xlsx" – Sales and revenue dataset
- "Requirements (1).txt" – Project requirements
- "README-1.md" – Project documentation

Expected Outcome

The project helps in understanding data visualization, KPI tracking, sales analysis, and business insight generation.
